# 30-Day Staff Systems Program

The full blueprint lives in the Claude artifact "Staff Systems Interview Blueprint"
(claude.ai/code/artifacts). This file is the on-disk index and the daily log.

## Weeks

- W1  Days 1-7    The machine underneath          ships: os_and_arch/benchmarks
- W2  Days 8-14   Kernel, drivers, the data plane ships: capstones/cap1_dma_chardev
- W3  Days 15-21  Concurrency you can prove       ships: capstones/cap2_lockfree_filter
- W4  Days 22-30  Scale, edge-to-cloud, the loop  ships: capstones/cap3_telemetry_ingest + 6 mocks

## Daily cadence (4h weekday / 6h weekend)

    60m  primary source (kernel tree, ISA manual, the paper) — not a blog summary
    75m  lab: compile it, run perf stat, commit the numbers
    45m  one LLD sketch or one HLD, written, timeboxed
    30m  articulation: explain today's topic aloud on a timer
    30m  capstone: one commit, every day

## Rules

1. No track advances on a day without an artifact: a measured number, a compiling
   file, or a written design. Reading is setup for progress, not progress.
2. Every notes/ file is written AFTER the lab, from memory, with the source closed.
3. If a week slips, cut the Edge AI track first and the HLD track last.
