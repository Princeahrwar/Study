# DSA Practice Log

One row per attempt. The log is how weak patterns become visible: after a few weeks, sort by pattern and look at where the "hint" and "time" columns are worst.

## How to fill it in

| Column | What to write |
|---|---|
| **Date** | Day of the attempt (`2026-10-14`) |
| **Problem** | Name and LeetCode number (`Two Sum (1)`) |
| **Area** | DSA area folder number (`01`, `07`) |
| **Pattern** | The pattern that solves it (`sliding window`, `monotonic stack`, `Dijkstra`) |
| **Diff.** | E, M or H |
| **Time** | Minutes to a correct solution, or `>45` if you stopped |
| **Hint?** | `no`, `hint` (needed a nudge), or `read` (read the solution) |
| **Cold?** | `1st` for a first attempt; `r1`, `r2`, `r3` for the 3-, 7- and 21-day revisits |
| **Revisit** | Date of the next revisit, if `Hint?` was not `no` |
| **Note** | One line: the insight you missed, or the bug you wrote |

**Revisit rule:** a problem you needed help with comes back 3, 7 and 21 days later, solved cold. It is owned when you solve it cold twice in a row.

**Targets:** easy 15 min, medium 30 min, hard 45 min.
